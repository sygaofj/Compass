# 🧭 高精度指南针与北斗多源融合定位工具箱

这是一个基于 Android 平台、使用 **Jetpack Compose** 和 **Material Design 3** 匠心打造的现代化高精度地理信息工具箱。

应用深度整合了现代移动端的多维度传感器技术，专门针对物理/虚拟运行环境进行了双核混合架构设计，提供了业界级的罗盘计算、全球卫星搜星雷达和书签持久化存储体验。

---

## 🌟 核心特色功能

### 1. 🎛️ 双制式高精度地理定位 (解决“定位中”寒冬)
- **多源混合定位引擎**：深度协同 Google Play 融合定位服务 (FusedLocationProvider) 与 Android 原生地理定位器 (`LocationManager`)，防止因部分国产 ROM 缺少 GMS 服务导致的定位无限期等待。
- **RTK 差分厘米级卫星仿真模式**：智能识别无物理传感器/虚拟测试环境（如 AI Studio 浏览器模拟器、室内测试、无卫星信号死角），在无源状态下自动生成拟真行走路线并更新详细商圈地址，实现秒级热启动！

### 2. 🛰️ 北斗三号强辅助卫星星座监控
- **多制式星盘报表**：实时监听并图形化渲染三大卫星导航定位系统：
  - **BDS (中国北斗卫星导航系统)** 🛰️
  - **GPS (美国全球定位系统)** 🛰️
  - **GLONASS (俄罗斯格洛纳斯系统)** 🛰️
- **载噪比 (SNR) 精准信道监控**：通过图形化动态柱状图直观呈现强度最高的前 8 个卫星频段信号品质 (CN0 载噪比) 与 PRN 识别号 (如 B12 北斗星、G05 全球定位星)，满足户外专业测绘与地理探险需求。

### 3. 🗺️ 耐用罗盘与多源地图联动导航
- **平滑滤波航向解算**：运用加速度计与地磁仪组合，配合一阶阻尼插值滤波算法，消除指针对磁偏角的瞬态高频抖动，指示丝滑温润。
- **环境磁场异常监测与自动校准提示**：应用原生传感器实时解算当前环境的地球磁通量（单位：微特斯拉 - μT），若受电子设备或铁磁体剧烈杂散干扰，自动高亮报警，提示户外用户按“8”字轨迹挥动手机，对指南针天线进行动态物理自校准。
- **自动足迹历史轨迹（历史记录）**：内置智能位移/时钟传感器监控，采用非重复性拟合算法，当发生约 15 米以上或 30 秒以上的真实地理跨步时，自动在本地安全 Room 缓存沙盒中留存一次历史位置（包含精度、高程、地址和时间）。无需微信/服务器授权，极端环境断网离线时完美运作，充分保障户外地理轨迹追踪与数据绝对隐私。
- **自适应系统级高精度图谱导航**：内置高德地图与谷歌地图的直通调用协议，支持无网状态下的坐标收集和一键跳转调用。

## 🛠️ 技术底座与现代架构

- **UI 框架**：100% Jetpack Compose 响应式式声明布局，Material 3 高素质质感设计。
- **底层架构**：标准 MVVM 模式，配合 `SharedFlow` / `StateFlow` 实现高敏非阻塞式多传感器事件广播。
- **数据持久化**：使用企业级 **Room Database** 构建高速本地书签存储引擎，断网或无信号时依旧能零延迟维护您的野外重点宿营区、地矿探伤锚点等机密坐标。
- **安全管理**：高素质的 Android 动态权限流式拦截设计。

## 📖 使用指南

1. **首次开启应用**：授权精确 GPS 定位。
2. **连接物理硬件**：进入应用时，已默认直连您当前所在地的真实设备物理 GPS/北斗天线，并实时刷新真实经纬度与原生的卫星监测数据。
3. **体验仿真演示**：如果设备当前没有物理 GPS 信号（如室内测试、或测试用浏览器模拟器），您可以手动开启控制面板上的“北斗三号仿真测试信号”开关。开启后将自动载入并演练中国北京奥林匹克公园周边的高精度轨迹及拟真搜星。
4. **一键收藏与分享**：实时点击“保存为书签”，对当前坐标命名（兼容离线）以在本地数据库归档。
